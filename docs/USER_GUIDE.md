# 外贸水印相机 · 操作手册

> 版本：v1.0 · 最后更新：2026-06-25
> 适用对象：终端用户（外贸从业者）
> 维护规则：每次功能更新需同步修订本文档对应章节。

---

## 快速上手（3 步拍出带水印的照片）

1. **选模板**：打开小程序，首页点选一个水印模板（默认「极简模板」）。
2. **拍照**：点「开始拍照」→ 取景框内会出现水印浮层 → 填好字段 → 点拍照按钮。
3. **完成**：自动跳到详情页，可继续调整水印或保存到相册。

---

## 一、首页

- 顶部显示「我的记录 · N」点进去是记录列表。
- 中间是模板网格（自定义模板在前，内置在后），点选高亮即为当前模板。
- 「开始拍照」：用当前选中模板进入拍照页。
- 「管理模板」：进入模板管理页新增 / 编辑自定义模板。
- 「使用说明」：弹出快速指南弹窗。

---

## 二、拍照页

### 2.1 取景与水印

- 取景框实时显示相机画面，水印浮层叠加在上方。
- **拖动水印**：单指按住水印块拖动，不会拖出画面。
- **缩放水印**：双指捏合放大缩小（0.5–2.0 倍）。
- **改字段**：直接点水印上的任意字段，弹出输入框编辑。
- **换位置**：点「位置」按钮，9 宫格里选一格（左上 / 上中 / 右上 / 左中 / 正中 / 右中 / 左下 / 下中 / 右下）。
- **换模板**：点底部「模板」按钮选择其他模板。

### 2.2 拍照

- 填好必填字段后点拍照按钮（圆形大按钮）。
- 会有一个闪光动画，随后自动渲染水印合成图片。
- 完成后自动跳转到详情页（不会回到拍照页，避免误操作）。

### 2.3 从相册选图

- 底部「相册」按钮可从手机相册选一张图，同样会叠加水印入库。

### 2.4 时间字段

- datetime / date / time 类型字段每次进入页面会自动刷新为当前时间。

## 三、记录列表

### 3.1 文件夹

- 顶部横向 Tab：「全部(N)」 / 「未分类(N)」 / 自定义文件夹 + 「+」。
- 点 Tab 切换查看对应记录。
- 点「+」新建文件夹（最多 30 个，名称 ≤20 字符）。
- **长按文件夹**：弹出「重命名 / 删除」。
  - 删除文件夹时可选「一起删除记录」或「移入未分类」。

### 3.2 记录卡片手势

#### 左滑（操作菜单）
- 在记录卡片上向左滑，露出 4 个按钮：
  - ✎ **重命名**：给照片起自定义名（留空恢复默认模板名）。
  - 📁 **移动**：把记录移到其他文件夹或未分类。
  - ⧉ **复制**：复制一份图片和记录到目标文件夹。
  - 🗑 **删除**：弹窗确认后删除（只删记录，不动相册）。
- 滑过一半自动展开，否则回弹收起。
- 点已展开的卡片会收起（不会进详情）。

#### 右滑（批量选中）
- 在记录卡片上向右滑 → 该记录被选中（出现勾选圈）。
- 进入批量模式后，顶部栏变化：
  - 标题变成「✕ 已选 X 条」+「全选」链接。
  - 左侧出现红色「删除」按钮。
  - 右侧保留「导出」「+ 新增」。
- **继续右滑其他记录**可继续选中。
- **点记录**也可切换选中。
- **左滑展开状态下右滑**：先收起回原位，再右滑才会选中（避免误触）。
- **退出批量模式**：点 ✕，或选中数归 0 自动退出。

#### 批量删除
- 批量模式下点红色「删除」→ 二次确认弹窗 → 确认删除。

### 3.3 导出模式

- 点顶部「导出」按钮进入导出模式。
- 文件夹 Tab 变成多选：可勾选多个文件夹，自动汇总其下所有记录（去重）。
- 顶部显示「已选 N 条」+「全选 / 取消」+「确认导出」+「取消」。
- 点「确认导出」→ 输入文件名 → 自动翻译缺失的描述列 → 生成 Excel → 打开 / 分享。
- 完成后自动退出导出模式。

### 3.4 清空

- 列表底部「清空本地记录」按钮：清空所有记录数据（不动相册文件），慎用。

## 四、详情页

### 4.1 查看模式

- 顶部显示带水印照片（等比缩放）。
- 点图片可全屏预览。
- 右上角 ⋮ 菜单 → 删除记录。
- 下方字段卡片展示所有字段（空值显示「—」）。
- 「保存到相册」：把当前带水印照片存到手机相册。

### 4.2 编辑模式

- 点「编辑」进入编辑模式：
  - 图片切到原图（避免看到两层水印）。
  - 水印层变为可拖拽 / 可缩放。
  - 三组滑块：缩放（0.5–1.5）/ 透明度（0.3–1）/ 宽度（0.28–0.85）。
  - 字段可实时编辑，水印内容同步刷新。
- 拖动水印时照片不会跟随滚动。
- 水印不会拖出照片范围。
- 点「保存」：重新渲染水印 → 更新记录。
- 点「取消」退出编辑。

### 4.3 OCR 核验（需部署）

- 详情页「识别与核验」卡片目前显示「未进行 OCR 核验」。
- 如需启用，需部署腾讯云 / 百度 OCR 云函数（开发者参考产品手册第八章）。

## 五、模板管理

### 5.1 新增自定义模板

1. 首页点「管理模板」→ 右上角「+」。
2. 填写：
   - **模板名称**（必填）
   - **描述**
   - **水印位置**：9 宫格选一格
   - **字号** / **内边距**
   - **背景色**：6 种预设（黑 / 白 / 绿 / 蓝 / 橙 / 红）
   - **文字色**：4 种预设（白 / 黑 / 绿 / 橙）
3. 添加字段：
   - 点「+ 添加字段」→ 填标签 → 选类型。
   - 类型：文本 / 多行文本 / 数字 / 日期时间 / 日期 / 时间 / 选择 / 定位。
   - 「选择」类型会自动生成 3 个默认选项，可改。
4. 校验：名称必填、至少 1 个字段、字段标签非空。
5. 点「保存」。

### 5.2 编辑 / 删除

- 点自定义模板卡片进入编辑。
- 卡片右上角 ⋮ → 删除确认。
- **内置模板不可编辑、不可删除**。

## 六、翻译词典

入口：记录列表顶部「📚 词典」按钮。4 个 Tab：

### 6.1 我的词典（自定义词典）

- 维护自己的中西对照词条，会优先参与本地翻译。
- 点「+」添加，输入中文和西班牙语。
- 点词条编辑或删除。

### 6.2 白名单

- **白名单内的词不参与翻译，原样保留。**
- 上方「自定义白名单」：自己加的词（如产品专有名词）。
- 下方「内置白名单」：系统预设的单位 / 货币 / 规格缩写（只读）。
- 点 ✕ 删除自定义白名单词。

### 6.3 内置词典

- 只读展示系统内置的约 130 条中西对照词。
- 顶部搜索框可按中文或西语关键字过滤。

### 6.4 翻译引擎

#### 选择引擎
- 顶部横向滚动选择 7 家之一：DeepSeek / 智谱GLM / 通义千问 / 阿里百炼 / MiniMax / 小米MiMo / 自定义。
- 选中的会高亮（绿色描边）。
- 切换后自动加载该引擎的配置（互不覆盖）。

#### 填写配置
- **Base URL**：通常切换引擎会自动填充，可改。
- **Model**：通常自动填充默认值，可改成你想要的模型名。
- **API Key**：去对应平台官网申请，填入即可。
- 三个字段**边输入边自动保存**，不用点保存按钮。

#### Prompt 自定义
- 默认 prompt 已内置，不用改也能用。
- 想自定义：在文本框输入你的 prompt，支持 4 个占位符：
  - `{source}` 源语言、`{target}` 目标语言、`{whitelist}` 白名单词列表、`{text}` 待翻译文本。
- 「保存」后永久生效。
- 「恢复默认」回到系统默认 prompt。
- 下方实时预览当前 prompt 对 `con luz y música` 的翻译效果。

#### 测试翻译
- 点「测试翻译」按钮，结果会显示：
  - 译文
  - ✅ 走了 API（含 provider 和耗时）/ ⚠ 全部本地命中 / ⚠ 未配置 API / ❌ API 失败
  - 未命中本地词库的词列表
  - 失败原因（如有）

#### 多家引擎配置
- 每家引擎的 Base URL / Model / API Key 独立保存。
- 切到 A 填好 A 的配置 → 切到 B 填好 B 的配置 → 切回 A，A 的配置还在。
- 最后选中的引擎会被记住，下次进来仍是它。

## 七、导出 Excel 详解

### 7.1 列说明

| 列 | 内容 |
|---|---|
| FOTO | 水印照片（原始字节嵌入，不压缩） |
| CODIGO | 货号 |
| DETALLADOS | 西语描述 |
| 描述 | 中文描述 |
| PRECIO | 单价 |
| CANTIDAD DE CAJA | 每箱件数 |
| CUANTAS CAJAS | 件数 |
| CUBICO | 体积 |
| PESO | 重量 |

### 7.2 自动翻译

- 如果某条记录只填了西语描述没填中文 → 导出时自动译成中文填入。
- 如果只填了中文没填西语 → 自动译成西语填入。
- 翻译优先用本地词典，未命中调 LLM API。
- 导出过程中会在 console 输出每行的翻译诊断（开发者可见）。

### 7.3 导出格式

- **主路径**：生成真实 `.xlsx` 文件（OOXML 格式），图片以原始字节嵌入不压缩，保持原画质。
- **自动回退**：如果 xlsx 生成失败（极少见），会自动回退生成兼容的 `.xls` 文件，仍可打开。
- 文件后缀：主路径 `.xlsx`，回退路径 `.xls`。
- 导出后默认用 `wx.openDocument` 打开，如打开失败回退为分享文件给微信好友 / 文件传输助手。

## 九、常见问题

### Q1：拍照后图片存在哪？
A：带水印照片和原图都存在小程序的 `USER_DATA_PATH`。清理小程序会丢失，重要照片请用详情页的「保存到相册」另存。

### Q2：翻译没生效 / 还是原文？
A：
1. 进「翻译词典」→「翻译引擎」→ 点「测试翻译」看诊断。
2. 如果显示「⚠ 未配置 API」→ 填好 API Key。
3. 如果显示「❌ API 调用失败」→ 检查小程序后台「服务器域名」是否添加了对应 API 域名（如 `api.deepseek.com`）。
4. 如果显示「⚠ 全部本地命中」→ 说明本地词典已覆盖，未调 API，这是正常的。

### Q3：切换引擎后 model 变回默认？
A：已修复。每家引擎的 Base URL / Model / API Key 独立保存，切换不会覆盖。

### Q4：左滑展开后右滑为什么没选中？
A：这是设计——左滑展开状态下右滑会先收起回原位，再右滑才会选中，避免误触。

### Q5：导出的 Excel 打不开？
A：现在导出的是真实 `.xlsx` 文件（OOXML 格式），用 Excel / WPS / Numbers 都能打开。如果极少数情况生成 xlsx 失败，会自动回退生成兼容的 `.xls`，仍可打开。如仍打不开，会用分享文件方式发给你。

### Q6：自定义白名单词不生效？
A：白名单大小写不敏感。检查「翻译引擎」→ Prompt 预览里 `{whitelist}` 是否包含你的词。改完白名单后预览会自动刷新。

### Q7：多家引擎怎么切换？
A：「翻译引擎」Tab 顶部横向滚动，点哪个就用哪个。每家配置独立保存，切回来还在。最后选中的会被记住。
